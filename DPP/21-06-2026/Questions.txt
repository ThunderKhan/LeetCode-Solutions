# DPP #1: Two Pointers on Sorted Arrays

Based on: **LeetCode 167. Two Sum II – Input Array Is Sorted**

This practice set strengthens the "sorted array + two pointers" pattern. Each problem introduces a new twist and increases in difficulty.

---

## Problem 1: Closest Pair to Target

**Difficulty:** Easy
**Concept Tag:** Two Pointers → Minimize Difference

### Description

Given a sorted array `nums` and an integer `target`, find two distinct elements whose sum is closest to `target`.

Return the absolute difference between their sum and `target`.

It is guaranteed that the array contains at least two elements.

### Constraints

* 2 ≤ nums.length ≤ 10^5
* -10^9 ≤ nums[i] ≤ 10^9
* nums is sorted in non-decreasing order
* -10^9 ≤ target ≤ 10^9

### Example 1

Input:

nums = [1,3,5,8,12]
target = 10

Output:

1

Explanation:

The closest sum is 3 + 8 = 11.

|11 − 10| = 1.

### Example 2

Input:

nums = [-5,-2,4,10]
target = 3

Output:

1

Explanation:

The closest sum is -2 + 4 = 2.

|2 − 3| = 1.

## Problem 2: Number of Pairs Smaller Than Target

**Difficulty:** Medium
**Concept Tag:** Two Pointers → Counting Instead of Finding

### Description

Given a sorted array `nums` and an integer `target`, count the number of pairs (i, j) such that:

* 0 ≤ i < j < n
* nums[i] + nums[j] < target

Return the total number of valid pairs.

### Constraints

* 2 ≤ nums.length ≤ 10^5
* -10^9 ≤ nums[i] ≤ 10^9
* nums is sorted
* -10^9 ≤ target ≤ 10^9

### Example 1

Input:

nums = [1,2,3,4]
target = 6

Output:

4

Explanation:

Valid pairs are:

(1,2), (1,3), (1,4), (2,3)

### Example 2

Input:

nums = [-2,0,1,3]
target = 2

Output:

3

Explanation:

Valid pairs are:

(-2,0), (-2,1), (-2,3)

## Problem 3: Treasure Caravan

**Difficulty:** Medium
**Concept Tag:** Two Pointers + Duplicate Handling

### Description

A caravan carries gems sorted by weight. The leader wants to form teams of two camels whose total load equals exactly `target`.

Different camels may carry gems of the same weight.

Return the number of distinct pairs (i, j) such that:

* i < j
* weights[i] + weights[j] = target

Each index may participate in multiple pairs.

### Constraints

* 2 ≤ n ≤ 10^5
* -10^9 ≤ weights[i] ≤ 10^9
* weights is sorted

### Example 1

Input:

weights = [1,1,2,2,3,3]
target = 4

Output:

5

Explanation:

There are four (1,3) combinations and one (2,2) combination.

### Example 2

Input:

weights = [2,2,2,2]
target = 4

Output:

6

Explanation:

Every pair is valid.

4C2 = 6.

## Problem 4: Circular Pair Search

**Difficulty:** Hard
**Concept Tag:** Two Pointers → Rotated Sorted Array

### Description

You are given an array obtained by rotating a sorted array.

Determine whether there exists a pair of distinct elements whose sum equals `target`.

Return true if such a pair exists, otherwise return false.

All elements are distinct.

### Constraints

* 2 ≤ n ≤ 10^5
* -10^9 ≤ nums[i] ≤ 10^9
* The original array was sorted and then rotated

### Example 1

Input:

nums = [11,15,2,4,7,9]
target = 13

Output:

true

Explanation:

11 + 2 = 13

### Example 2

Input:

nums = [8,10,14,1,3]
target = 17

Output:

true

Explanation:

14 + 3 = 17

### Hints

Hint 1:

A rotated sorted array still has a smallest and largest element.

Hint 2:

Find the pivot position.

Hint 3:

Treat the array as circular and use two pointers.

## Problem 5: Minimum Window Pair Difference

**Difficulty:** Hard
**Concept Tag:** Two Pointers + Optimization

### Description

Given a sorted array `nums`, consider every pair (i, j) where i < j and nums[i] + nums[j] ≥ target.

Define:

cost = nums[j] − nums[i]

Return the minimum possible cost among all valid pairs.

Return -1 if no valid pair exists.

### Constraints

* 2 ≤ n ≤ 10^5
* -10^9 ≤ nums[i] ≤ 10^9
* nums is sorted
* -10^9 ≤ target ≤ 10^9

### Example 1

Input:

nums = [1,3,5,8,10]
target = 12

Output:

2

Explanation:

Possible pairs:

3 + 10 = 13 → cost = 7

5 + 8 = 13 → cost = 3

8 + 10 = 18 → cost = 2

Minimum cost is 2.

### Example 2

Input:

nums = [1,2,4]
target = 10

Output:

-1

Explanation:

No pair satisfies the condition.

### Hints

Hint 1:

Sorted arrays naturally bring larger numbers closer together.

Hint 2:

Whenever the current pair satisfies the target, try reducing the distance between pointers.

Hint 3:

A linear two-pointer sweep explores all promising candidates efficiently.

## Pattern Progression

1. Closest Pair to Target

   * Basic pointer movement.

2. Number of Pairs Smaller Than Target

   * Counting multiple pairs simultaneously.

3. Treasure Caravan

   * Handling duplicates and combinatorics.

4. Circular Pair Search

   * Applying two pointers on a rotated sorted array.

5. Minimum Window Pair Difference

   * Optimizing a value rather than finding an exact sum.

Mastering these five variants will make the "Two Pointers on Sorted Arrays" pattern much more intuitive and transferable to harder interview and competitive programming problems.
